# Prison Management System



This is a Python-based Prison Management System developed as an academic project in Class 12.



## Features

\- Add prisoner details

\- Store data using MySQL

\- Command-line based system



## Technologies Used

\- Python

\- MySQL

## How to Run
1. Install Python (3.x)
   
2. Install MySQL
   
3. Install MySQL connector:
   
   pip install mysql-connector-python
4. Run:
   
   python prison_management.py

This project was developed as an academic project to demonstrate
